## Estructura
Una carpeta por tema (`01_variables_y_tipos` ... `12_entrada_y_salida`) con un archivo por ejercicio: `ejercicio_<tema>_<número>.py`.

## Cómo ejecutar
Desde la carpeta del tema:

    python ejercicio_3_2.py

Notas:
- `11_modulos_y_paquetes/ejercicio_11_3.py` importa `calculadora.py` (misma carpeta).
- `12_entrada_y_salida/ejercicio_12_3.py` lee el `registro.txt` que crea `ejercicio_12_2.py`.
